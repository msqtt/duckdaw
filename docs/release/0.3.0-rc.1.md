# 0.3.0-rc.1 dependency and release notes

## New test dependencies

- `@playwright/test@1.62.1`: Microsoft Playwright, Apache-2.0, used only in development/CI. Chromium, Firefox, and WebKit binaries are installed in CI and are not shipped in the application bundle.
- `@axe-core/playwright@4.13.0`: Deque axe-core Playwright integration, MPL-2.0, used only for browser accessibility checks and not shipped in the application bundle.

Package names, upstream repositories, licenses, Node requirements, and exact versions were checked before installation. The package lock is authoritative for transitive integrity hashes.

## Removed dependencies

Repository-wide import/config searches found no runtime or script references for `@google/genai`, `express`, `dotenv`, `autoprefixer`, `tsx`, direct `esbuild`, or `@types/express`; they were removed. Vite's optional `tsx` peer remains transitive and is pinned through a security override.

## Runtime license boundary

FFmpeg core/WASM remains self-hosted and same-origin. It is loaded only when compressed export is requested. `@ffmpeg/core@0.12.10` declares `GPL-2.0-or-later`; `@ffmpeg/ffmpeg@0.12.15` and its types declare MIT. The deployed app includes a discoverable `/THIRD_PARTY_NOTICES.txt`, the complete GPL-2.0 text, and the exact upstream release/source and build-script links. DuckDAW does not modify the packaged core JavaScript or WASM assets. Any future core replacement or modification requires a renewed license/source review before production.

## Security result

The candidate uses exact direct versions plus exact compatible overrides for `@babel/core`, `nanoid`, `postcss`, `tsx`, and nested `esbuild`. `npm audit --audit-level=high` and the full JSON audit must pass before staging or release promotion. No `npm audit fix --force` is permitted.

## Candidate validation evidence

Validated locally on 2026-08-18 before staging commit:

- Vitest: 42 files, 278 tests passed.
- Playwright: Chromium, Firefox, and WebKit combined matrix, 18/18 passed; includes package download/reload, Audio/MIDI undo workflows, recovery, unsupported APIs, SPA/deployment metadata, deployed license assets, and serious/critical axe checks.
- TypeScript no-emit, Vite production build, `git diff --check`, and frozen bundle budgets passed. DAWApp is 392.15 KiB / 400 KiB; no budget was raised.
- Exact direct dependency tree is clean and `npm audit --audit-level=high` reports 0 vulnerabilities.
- Independent release review and follow-up license review report no open P0/P1 findings.

Remote CI, the Netlify staging deploy, and `daw-sit.msqt.fun` DNS/TLS/commit metadata remain post-push staging gates and are not claimed by this local evidence.
